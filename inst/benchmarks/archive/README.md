# Archived benchmark workflows

`pilots/geosse-parameter-recovery/` preserves the earlier GeoSSE parameter-recovery scripts, settings and existing outputs. It is historical, not the current publication design. Run its commands from the repository root; paths now point to this archive.

New runs belong in the four numbered families. Stochastic-mapping checks are separately organized under `../stochastic-mapping/`.

See [migration.md](migration.md). No original project inputs, remote results or scientific settings were deleted or changed.
