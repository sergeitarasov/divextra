# Historical fixed-parameter checks

Imported from roihu-constant-size-50/preparation/likelihood-checks.csv. These compare log likelihoods without optimization at fixed generating parameters, using the same tree/state data and conditioning. original-validation.R is a provenance copy and also includes a later optimization smoke test; it is not a standalone script in this evidence-only folder.

The original tree IDs refer to the 750-tree constant-rate pilot, not the new 1,500-tree publication run. Source data and model.R remain in the original project folder. No new GeoSSE calculations were run during migration.
